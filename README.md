# testproofOfdelivery

A sandbox repo for testing [Proof of Delivery](https://proof-of-delivery-two.vercel.app) bounties on NEAR testnet.

Open issues here are paid bounties: open a pull request that says `Fixes #<issue>`, get it merged, then press **Check my PR** on the job page to be paid automatically.

## Contracts

- [`counter/`](counter/README.md) — a minimal `i64` counter contract in Rust with `near-sdk` 5.x
  (`get_num`, `increment`, `decrement`, `reset`). See its README for how to build, test and deploy
  to testnet.
